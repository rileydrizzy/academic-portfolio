# Academic Portfolio

A responsive, single-page academic portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Replace the highlighted placeholder text in `index.html` with your information.
2. Add your CV at `assets/cv.pdf` (or change the CV link in the page).
3. In your GitHub repository, open **Settings → Pages** and deploy from the branch containing these files.

The site has no build step or dependencies. The included `.nojekyll` file ensures GitHub Pages serves it as a plain static site.
