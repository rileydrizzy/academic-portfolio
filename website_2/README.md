# AI / ML Engineer Portfolio Template

A single-page, dependency-free portfolio designed for an AI / ML Engineer. It runs as plain HTML, CSS, and JavaScript—ideal for GitHub Pages.

## Replace placeholders

Open index.html and replace every value in square brackets, such as [Your Name], [your.email@example.com], and [project-one-case-study-or-repository-url].

The three project cards are structured around the signal hiring teams need:

- The real-world problem and your technical contribution.
- The tools and delivery context.
- A specific, defensible outcome.

Replace all placeholder link values with a complete https URL, or remove the corresponding link.

## Publish with GitHub Pages

GitHub Pages can publish from the repository root or a docs directory, not from website_2 directly. Before publishing, either move the contents of this directory to the repository root, or rename website_2 to docs. Then configure GitHub Pages to deploy that source and commit when you are ready.

There is no build step and no dependency installation.
